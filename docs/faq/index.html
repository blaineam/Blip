Questions & Answers

Everything people ask about Blip on the Mac, iPhone and iPad.

Getting started

What do I need to run it?

A Mac with Apple silicon on macOS 14 Sonoma or later, or an iPhone or iPad on iOS 17 or later.

Does Blip work on Intel Macs?

Blip is built exclusively for Apple Silicon (M1, M2, M3, M4 and newer). It uses ARM64-specific optimizations and Apple Silicon IOKit interfaces for GPU and thermal monitoring.

Is there an iPhone and iPad app?

Yes — Blip Stats 2.0 is one free app across Mac, iPhone, and iPad. The iOS app shows live device stats with drill-in details, runs Blip Bench (including the Neural Engine), tests network and disk speed, does ping and traceroute with an offline hop map, and ships Home Screen widgets and Shortcuts.

Can I install it with Homebrew?

Yes: brew install --cask blaineam/tap/blip installs the direct-download Mac app.

How do I build from source?

Clone the repo, install XcodeGen (brew install xcodegen), run xcodegen generate, then build with Xcode or xcodebuild. See the README for full instructions.

Using Blip

Why do some Mac stats need Blip Helper?

The App Store keeps Mac apps in a sandbox, so fans, temperatures, GPU, disk I/O, battery health and top processes come through the free Blip Helper. The direct download reads them itself.

How does the hover detail panel work?

Hover over any row in the main popover to reveal a detailed sub-panel to the side — just like iStats Menus. It shows charts, breakdowns, and top processes for that category.

Can I customize what shows in the menu bar?

Yes. Open Settings from the gear in the popover and choose which items show: CPU, Memory, Disk, GPU and the network dot, with or without labels, in a horizontal or stacked layout and the colors you like.

How much memory does Blip use?

Typically around 42 MB physical footprint. Blip shows its own memory usage in the popover footer so you can always check. The binary itself is around 2 MB.

Privacy, price and availability

Is it safe?

Yes. Blip is open source and every Mac release is notarized by Apple. There are no analytics, no crash reporters and no servers: everything runs on your device.

Is Blip really free?

Yes, on every platform. The App Store app for Mac, iPhone and iPad, the direct download and the Homebrew cask are all free, with nothing to unlock.

Is Blip available in the European Union?

Yes. Blip is on the App Store everywhere in the European Union, France included, and the direct download and Homebrew cask work everywhere.
