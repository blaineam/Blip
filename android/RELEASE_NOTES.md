## Beta: please tell us what breaks

**Blip for Android is a beta.** It passes its tests on Android emulators but hasn't been tried on a physical device yet. **If you run into a problem, please [open an issue](https://github.com/blaineam/blip/issues)** with your phone's model and Android version. Reports that it works on your device help too.

## Install

For Android 10 or newer (arm64, 32-bit ARM and x86_64). Download the `.apk`, open it on your device, and allow your browser or file manager to install apps when Android asks. Updates install over the old version. You can check your download against `SHA256SUMS.txt`.

No runtime permissions, no tracking: nothing leaves the device unless you run a network test.
